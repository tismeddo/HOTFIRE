# HOTFIRE

**H**ormonal **O**ptimization of Lung **T**ransplant Recipients **F**or **I**mprovements in **R**ehab and **E**xercise Capacity

Draft protocol for investigator and IRB review. Principal Investigator: Diego Marin, DO, FCCP — Pulmonary and Critical Care Medicine.

A single-center prospective cohort of adults undergoing lung transplant evaluation, with an embedded randomized, double-blind, placebo-controlled pilot of testosterone cypionate in 20 listed men with endocrinologist-confirmed hypogonadism.

- `index.html` — protocol overview site
- `hotfire-protocol.pdf` — print version

This is a conceptual draft, not an approved clinical protocol or a treatment order.
